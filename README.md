# HR Workforce Data Analysis

## 📊 Project Overview

This is an end-to-end HR Workforce Data Analysis project developed to analyze employee information, department structure, salary distribution, job roles, experience, and employee performance.

The project uses **SQL, Python, and Power BI** to perform data cleaning, analysis, visualization, and business insight generation.

## 🎯 Project Objectives

- Analyze employee workforce data
- Understand department-wise employee distribution
- Analyze salary and compensation patterns
- Compare job roles and base salaries
- Analyze employee experience and performance ratings
- Identify important HR trends and patterns
- Build an interactive Power BI dashboard
- Generate data-driven business insights

## 🛠️ Tools & Technologies

- **SQL / MySQL** – Data storage, data cleaning and analysis
- **Python** – Data cleaning, exploration and analysis
- **Pandas** – Data manipulation
- **Matplotlib & Seaborn** – Data visualization
- **Power BI** – Interactive dashboard and reporting
- **GitHub** – Project documentation and version control

## 📁 Dataset

The project contains four datasets:

### 1. emp_info.csv
Contains employee demographic and employment information such as:
- Employee ID
- Name
- Date of Birth
- Gender
- Marital Status
- Qualification
- City
- State
- Country
- Hire Date
- Active Status

### 2. department.csv
Contains department information:
- Department ID
- Department Name
- Cost Center

### 3. emp_salary.csv
Contains employee salary and performance information:
- Employee ID
- Department ID
- Role ID
- Years of Experience
- Basic Salary
- PF Deduction
- ESI Deduction
- Performance Rating
- Performance Bonus
- Gross Salary

### 4. job_roles.csv
Contains job role information:
- Role ID
- Position
- Base Salary
